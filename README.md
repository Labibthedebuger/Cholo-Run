# 🎮 Cholo Run

## 📖 Description

**Cholo Run** is an endless runner video game built using the **iGraphics library in C++**.
The game features immersive environments inspired by the streets of **Dhaka** and the scenic beauty of **rural Bangladesh**.

Players navigate through culturally rich settings while demonstrating core graphics programming concepts such as:

* Object movement
* Collision detection
* Dynamic background rendering

---

## ✨ Features

* 🏙️ **Dhaka & Village Themes**
  Run through detailed environments including busy Dhaka footpaths and peaceful village roads.

* 🚧 **Obstacle Navigation**
  Dodge obstacles placed along the path to keep your run going.

* 🎨 **Dynamic Visuals**
  High-quality assets featuring localized elements like Bengali shop signboards.

* 🎥 **Smooth Animations**
  Fluid character movement and environment scrolling implemented in C++.

---

## 🛠️ Project Details

* **IDE:** Visual Studio 2013
* **Language:** C, C++
* **Platform:** Windows PC
* **Genre:** Endless Runner / 2D Action

---

## ▶️ How to Run the Project

### 🔧 Requirements

Make sure you have:

* Visual Studio 2013
* iGraphics Library (included in this repository)

### 🚀 Steps

1. Open **Visual Studio 2013**
2. Go to `File → Open → Project/Solution`
3. Select the `.sln` file from the repository
4. Click `Build → Build Solution`
5. Run using `Debug → Start Without Debugging`

---

## 🎮 How to Play

### 🎹 Controls

| Action     | Key             |
| ---------- | --------------- |
| Move Left  | A / Left Arrow  |
| Move Right | D / Right Arrow |
| Jump       | W / Up Arrow    |

---

## 📜 Game Rules

* The game is an **endless runner**
* Travel as far as possible without hitting obstacles
* Avoid obstacles to keep running
* Stay on the clear road path
